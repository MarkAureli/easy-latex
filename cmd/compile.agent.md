# el compile (`compile.go`)

**Engine resolution** (before pass 1): `resolveEngine(cfg, --engine)` picks one of `pdflatex` / `xelatex` / `lualatex` with precedence `--engine` flag → magic comment `% !TEX program = <engine>` (or `TS-program`, scanned in first ~20 lines of `cfg.Main`, regex `magicEnginePattern`) → `cfg.Engine` → `pdflatex` default. Result validated by `validateEngine`. Binary located via `findTool(engine)`. All three engines share identical CLI flags and log conventions, so `runEngine` (formerly `runEngine`) is engine-agnostic; only the binary path differs.

Stages (`runCompile` → `compileRun` methods): `prepareCompile` (config, check names, aux dir, post-compile `.sty` + env probe → `injectStys`, engine) → `syncBibCache` (step 1) → `runPasses` (steps 2–10; `pass(draft)` = `runEngine` + print errors on failure) → env/cmd tables → `copyPDF` → `runSourceChecks` + `RunPostCompileChecks` → `appendDiagsToLog` → `printReport` → `openFile` (`--open`).

Pass sequence:
1. **Hash check** — if `bibliography.bib` changed since last compile/bib parse (`bib.BibFileChanged`), announces "bibliography.bib changed, re-parsing…", auto-runs `bib.AllocateCacheEntries`, save renames to `.el/renames.json`, update hash
2. **Pass 1** — `runEngine` with `draft=true` (`-draftmode`, no PDF written); output not shown (bib warnings expected here). On failure with an existing `.bbl`: delete it, retry once; still failing → print errors
3. **Bib file discovery fallback** — if `cfg.BibFiles` empty after pass 1, parse `.aux`/`.bcf` to find them, save to config
4. **Cite-key rewrite** — if `.el/renames.json` non-empty (`bib.LoadRenames`), announces key renames and `.tex` file rewrites, rewrite `\cite{}` in all `.tex` files via `rewriteCiteKeys` (comment cut via `texscan.StripComment`, so `\%` is not a comment), clear renames, re-run engine in draft mode (`discoverBibFiles`, `applyRenames`, `writeBib`)
5. **Write bibliography** — `bib.WriteBibFromCache`: extract cited keys from `.aux`/`.bcf` (`citedKeysFromArtifacts`), filter out keys defined in generated `.bib` files (`generatedBibKeys` — any `\bibdata{}` source not in `cfg.BibFiles`, e.g. revtex `citeautoscript`'s `<stem>Notes.bib`), write only those entries to `bibliography.bib` with all config transforms applied; update hash. Cited keys present in the global bib cache but missing from the project bib file are materialised here (auto-import on compile).
6. **Detect bib tool** — `.bcf` present → `biber`; `.aux` contains `\bibdata{` → `bibtex`; else none
7. **Bib pass** — `runBibTool`; biber uses `--input/output-directory`; bibtex runs from inside aux dir with `BIBINPUTS=..:` and `BSTINPUTS=..:` (both needed so bibtex finds `.bib` and `.bst` files in project root)
8. **Pass 2** — draft pass; errors printed on failure
9. **Pass 3–4** — up to 2 additional draft passes if output contains "rerun" (`for range 2` loop), stabilizing cross-references and citations
10. **Final pass** — one non-draft `runEngine` call (no `-draftmode`); this is the only pass that writes `<stem>.pdf`. All earlier passes use `-draftmode` so PDF viewers do not reload mid-compile when bib/rerun stabilization is in progress. Its warnings (`ofKind(diags, logWarning)`) form the `Warnings:` section.

Env probe: every compile is injected (`\RequirePackage{el-envprobe}\input{main}`, `-jobname`, as for post-compile checks) with a generated `.el/el-envprobe.sty` (`internal/envprobe`) that hooks `env/NAME/begin|end` for every scanned env (+ figure/table) and logs `\@captype` before/after to `.el/<stem>.elprobe`. Float = captype newly set/changed (so wrappers nested in a float aren't misclassified). Lists are deliberately not classified. Works with real args; no-op without `\AddToHook` (kernel < 2020-10). The `begin` hook runs BEFORE the env's own begin code, hence the before/after diff. The `end` write is skipped when `\currentgrouptype=6` (inside an alignment, e.g. after the last `\\` of tabular/matrix): any non-expandable token there starts a cell and adds a phantom empty row.

Env table: after the final pass, `updateEnvTable` (`cmd/envs.go`) merges `texscan.ScanEnvs` (args/theorem) over the reachable tex files plus project `.sty`/`.cls` (`texscan.FindFilesByExt`) into `.el/envs.json` (`{env: {args, theorem, float}}`; `float` comes only from the probe (envs that never ran stay unflagged)); found entries overwrite stored ones, absent ones are kept; best effort. `updateCmdTable` does the same for commands (`texscan.ScanCmds` → `.el/cmds.json`, `{cmd: mandatory-arg count}`). Read by nvim snippets: plain-env completion places `{}` per mandatory arg; theorem-style envs (`theorem: true`) get `\label{env:}`; floats (`float: true`, plus built-in figure/table) get `\centering` + `\caption{\label{type:|}` + `}` with `type` = env name minus `*`.

Post-compile: copy `<stem>.pdf` from `.el/` to project root. If checks enabled: run `pedantic.RunSourceChecks` + `pedantic.RunPostCompileChecks` + spell-check. With `--fix`, the source-phase detector runs both before and after `pedantic.RunSourceFixes`; the pre/post diff goes into a `Pedantics (fixed)` section (default colour, bold header), and the post-fix diagnostics + post-compile diagnostics go into `Pedantics (remaining)` (yellow). Output sections, in order with blank line between non-empty sections: `Pedantics (fixed)` (when `--fix`), `Pedantics`/`Pedantics (remaining)`, `Misspellings`, `Warnings` (compile-time pdflatex warnings, yellow). Followed by a yellow summary `N pedantic(s), M misspelling(s), K warning(s)` — fixed pedantics are excluded from the count. `Compiled successfully -> <pdf>` always prints when PDF made; warnings never change the exit code. When any post-compile check is enabled: writes each enabled check's embedded `.sty` (`pedantic.PostCompileStys`) to `.el/`, injects via `\RequirePackage{<pkg>}…\input{main.tex}` (sorted package order) with `TEXINPUTS` pointing to aux dir and `-jobname=<stem>`. Currently: `no-math-linebreak` → `el-mathpos.sty`; `no-section-linebreak` → `el-sectionpos.sty`; `no-orphan-line` → `el-orphan.sty`.

**Editor integration** (`cmd/vimtexlog.go`): after the checks, `appendDiagsToLog` appends pedantic (`[el]`) and spelling (`[el:spell]`) diagnostics to `.el/<stem>.log` as `Package el Warning: file: [tag] msg on input line N.` (line 0 → 1), so VimTeX's `latexlog` parser lists them in `:VimtexErrors` as warnings (file is also in the text). `file:line: msg` form was rejected: parsed as type E (`%E%f:%l: %m`), making VimTeX report "Compilation failed!". Also re-emits lineless `Underfull|Overfull \vbox|\hbox ... while \output is active` lines as `Package el Warning: [vbox|hbox] ... on input line 1.` (VimTeX's efm only matches boxes with `at line N`). **File attribution**: `appendDiagsToLog(logPath, mainFile, …)` rewrites the log, inserting `**"file"` before every diagnostic (`annotateLogFiles`, uses `logFileTracker`; file unknown → main). VimTeX's efm has `%-P**\"%f\"` (file-stack push), so the next entry gets that file instead of the main-file fallback; pedantic/spell entries and lineless boxes get their own push. Over/Underfull entries are additionally preceded by a decoy `(el-unknown-file)` line, because VimTeX's `fix_paths_hbox_warning` otherwise rescans upward for `(file` (space-free names only) and overrides the file; the unreadable decoy makes it give up. Best effort; errors ignored. `runEngine` also sets `max_print_line=1000` so log lines aren't wrapped at 79 cols (otherwise `on input\nline N` splits and VimTeX loses the line number; also un-truncates terminal warnings).

Uses `internal/term` for ANSI colors (replaces inline color vars). Uses `bibLogger` (`cmd/biblog.go`) for bib operation messages.

Flags:
- `--open` / `-o` — call `open <pdf>` after success.
- `--fix` — apply `pedantic.RunSourceFixes` to source files before running checks (static-with-fix checks only); reports modified files. Mutually exclusive with `--no-check`.
- `--no-check` — skip all pedantic checks for this run (static and dynamic); also skips writing any post-compile `.sty` and `\RequirePackage` instrumentation. Mutually exclusive with `--fix`.
- `--engine` — override LaTeX engine for this run (`pdflatex`, `xelatex`, `lualatex`). Highest precedence in `resolveEngine`.

Log parsing (`cmd/texlog.go`): `parseLog(output) []logDiag` parses engine/bib-tool output once; `logDiag{Kind (logError|logWarning), File, Text, Context}`, `String()` = `File: Text`. `classifyLine` = single classifier (also used by `annotateLogFiles`): error patterns win, anchored (`^!`, `-file-line-error` form `<file>.<ext>:<line>: ` (extension required so echoed paragraph text like `3:12: ` can't match), `Error:`, `error (`, `(There were N errors)`, `fatal error`, biber `ERROR|FATAL - `) so a bare "error" in echoed hbox context stays a warning; warning patterns: warning, `WARN - `, undefined, multiply defined, Over/Underfull. `l.N` context lines attach to the preceding diagnostic. `runEngine` returns `[]logDiag`. Consumers: `printLogDiags` (failure / bib tool: errors if any, else warnings), `needsRerun` (matches `Text` only, not the file name), `ofKind(diags, logWarning)` → `Warnings:` section, summary count. A successful final pass reports its warnings even if it also printed a non-fatal error line.

`entriesBibFile(bibFiles)` — returns path of `bibliography.bib` from config bib list, or `""` if absent.

**Warning file attribution** — `parseLog` runs a `logFileTracker` (`cmd/logfiles.go`) over engine output, following `(./file.tex … )` nesting (spaces allowed in names; absolute/texmf paths ignored; diagnostic blocks not scanned, except: line after an `l.N` context line is scanned when it starts with `[`/`]`/`)`, or from byte/rune 79 on when the context is truncated with `...` at `error_line` (terminal output continues on that line; `runEngine` pins `error_line=79`, `half_error_line=50`); Over/Underfull `\hbox` blocks end after their one box-content line (terminal has no blank line there)). Warnings get `File` = project-relative file (printed as prefix). Errors unchanged (`-file-line-error`).

**Biber output**: `parseLog` drops `INFO - ` lines (incl. the `INFO - WARNINGS: n` summary); `WARN - ` counts as warning, `ERROR - `/`FATAL - ` as error.
