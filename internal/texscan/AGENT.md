# internal/texscan

Exports:

- `FindBibFiles(mainTex, dir string) []string` — scan `mainTex` and recursively included files for bib declarations (`\bibliography{}`, `\addbibresource{}`). Return dedup `.bib` names relative to `dir`. Append `.bib` if missing.
- `FindTexFiles(mainTex, dir string) []string` — return all `.tex` file paths reachable from `mainTex` via `\input{}`/`\include{}` (relative when `dir` is relative).
- `FindCiteKeys(mainTex, dir string) []string` — scan all reachable `.tex` files for `\cite{}`, `\citep{}`, `\citet{}`, `\citeauthor{}`, `\parencite{}`, `\textcite{}`, `\autocite{}`, `\fullcite{}` and variants; return sorted, deduplicated keys. Strips comments before matching. Optional citation arguments `[...]` are skipped.
- `ResolveFileContents(mainTex, dir string) error` — find `\begin{filecontents[*]}{*.bib}...\end{filecontents[*]}` blocks in all reachable tex files, write embedded content to disk as `dir/name.bib`, remove block from tex file. Called by `el init` (before `FindBibFiles`).
- `RewriteBibReferences(mainTex, dir string, newBibFiles []string) error` — rewrite `\bibliography{...}` and `\addbibresource{...}` in all reachable tex files. First occurrence per file replaced with new references; subsequent occurrences of same command type dropped.
- `StripComment(line string) string` — strip `%`-to-end-of-line comment (escaped `\%` preserved).
- `Classify(lines) [][]Class` (`classify.go`) — shared per-byte classifier over comment-stripped lines; state carries across lines, blank line ends pending args/open option lists. Classes: prose (`ClassText` running, `ClassStandalone` \footnote/\caption, `ClassHeading` \section/\item[…]/node text, `ClassCell` table/algorithm/bibliography cells; `IsProse()`), `ClassMath`, `ClassMarkup` (command names, structural braces/brackets, `$`/`\(`/`\[`, `\begin{…}`/`\end{…}`, `&`), `ClassOpaque`, `ClassVerbatim`. Rules:
  - `commands` table: per-argument roles (`argInline` inherits the surrounding prose kind; in math, `\text{…}`/`\intertext{…}` are running text, while `\mathrm{…}` etc. are opaque — use `\mathrm` for labels). Unlisted `[…]` options of known commands are opaque. **Unknown commands (incl. project-defined)**: all consecutive `[…]`/`{…}` groups opaque in text/code, `{…}` math in math. `\def`-family: unbraced name + `#n` + opaque body. `\verb`/`\lstinline` delimited → verbatim.
  - `environments` table: math, verbatim, code (TikZ/PGF/pgfplots/quantikz/forest/pspicture), cells; unknown envs inherit. `\begin{env}` args directly following on the same line are opaque.
  - Code mode: bytes opaque, `$` is TikZ calc syntax (not math); `\node`/`node` → after `[opts]`, `(name)`, `at (x,y)` the `{…}` is `ClassHeading`; option values of `codeProseKeys` (`xlabel`, `ylabel`, `zlabel`, `title`, `legend entries`) are `ClassHeading`; `\addlegendentry`/`\legend` via the table.
  - Robustness: stray `}`, `$`, `\)`, `\]`, `\end{x}` close the innermost matching frame (frames above are dropped).
  - `IsVerbatimEnv`, `IsMathEnv` expose the env table.
  - `ClassifyMath` adds a per-byte inside-math flag (delimiters excluded); `Analyze` returns `[]LineInfo{Classes, Math, End, OpensGroup}`: `End` = class of the innermost context open at line end, `OpensGroup` = a `{…}`/`[…]` group opened on the line is still open at its end. Pending args of known commands cross line breaks (LaTeX looks past them: `\\` + newline + `[1em]`); those of unknown commands and env args do not.
- `ProseRuns(file, content string) []ProseRun` — prose view of `Classify` for spell-check: one `ProseRun` per line with any prose byte; `Text` same byte length as the comment-stripped line, non-prose bytes, TeX length literals and ordinal suffixes after math blanked.
- `ScanEnvs(texFiles []string) map[string]EnvInfo` — `EnvInfo{Args, Theorem, Float}` per environment., where `Float` is left false (filled from the compile probe, `internal/envprobe`). `Theorem`: declared by `\newtheorem`/`\newmdtheoremenv`/`\declaretheorem`/`\spnewtheorem`/`\newtcbtheorem` (name lists, `*`, `[opts]` handled). `Args` (mandatory-arg count): declared (`\newenvironment[n]` minus optional default, `\NewDocumentEnvironment` spec `m/v/r/R`) wins; else min over occurrences of consecutive `{...}` groups after `\begin{env}` (skips `[...]`, stops at blank line). Verbatim-like envs and comments ignored. `ScanEnvDecls(files)` returns only declaration-derived data (declared arg counts, theorem set). `FindFilesByExt(dir, exts...)` lists files below dir (hidden dirs skipped). `cmds.go`: `ScanCmds(files, probed) map[string]int` — mandatory-arg count for every used or declared command (starred names are separate keys), each via `ResolveCmd(name, declared, provided, probed, usage)`: project declaration (`\newcommand[n]` minus optional default, `\def` `#n`, `\NewDocumentCommand` spec, `\DeclareMathOperator` 0, `\DeclarePairedDelimiter` 1 / `[n]` for X) > compile probe (`internal/cmdprobe`; beats a `\providecommand`-only declaration) > `BuiltinCmdArgs` (`cmds_builtin.go`: kernel/amsmath/common packages, ≥1-arg commands only; backs the probe where it aborts and stands in before the first compile) > usage mode (ties → smaller) of consecutive `{...}` groups (min would be pinned to 0 by `\mathcal H`, `\titleformat{\section}`) > 0. `probed` may be nil. `ScanCmdDecls(files) (args, provided)` = declarations only; `provided` = names declared only via `\providecommand`. `StoredCmdArgs(cmdsJSON)` = `BuiltinCmdArgs` overlaid by stored entries, except a stored 0 never overrides a built-in (stale pre-probe usage counts like `frac: 0`); other zeros kept so `\alpha` is known; `ProjectCmdArgs(cmdsJSON, files)` = that overlaid by `ScanCmds(files, nonzero stored)` (stored entries act as probe layer) — the pedantic `Context.CmdArgs` sources. `DocumentSpecMandatory(spec)` counts `m/v/r/R` (shared with envs and cmdprobe). `envtable.go` (generic `LoadTable[T]`/`SaveTable[T]`, used for envs.json and cmds.json): `LoadTable`, `SaveTable` (atomic, skips if unchanged), `ApplyEnvDecls` (refresh theorem flags + declared args, leave usage-derived args).

All non-prose functions strip comments before pattern matching.
